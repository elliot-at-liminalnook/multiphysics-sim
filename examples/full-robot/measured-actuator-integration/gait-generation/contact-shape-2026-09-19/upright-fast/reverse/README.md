# Forward/reverse qualification

The command is forward for four seconds, then reverse for six seconds.
The predeclared reversal metric requires at least 0.15 m of signed reverse
travel from 6 to 10 seconds. Observed: 0.34516 m, with all tracking and balance
checks passing. Foot lift and sampled collision also pass.

The generic forward report retains a failed net-displacement travel check: the
robot finishes only 0.02969 m from its starting point because it walked back.
That forward-only metric is not a reversal requirement. Qualification uses the
original signed reverse-travel requirement and the physical/geometry checks.
No threshold was changed.
